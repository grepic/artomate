### 1. ✅ Oprava navigace v menu (dvojité kliknutí)

**Problém:** Bylo potřeba kliknout dvakrát na položku menu, aby se zobrazila stránka.

**Příčina:** `st.radio` widget v kombinaci s podmíněným rerunem způsoboval, že první kliknutí jen změnilo hodnotu widgetu, ale stránka se načetla až po druhém kliknutí.

**Řešení:**
- Změna z `st.radio` na `st.selectbox` pro okamžitou navigaci
- Přidán explicitní `st.rerun()` po změně stránky
- Jednokliková navigace nyní funguje okamžitě

```python
# Před:
page = st.radio("Select Page:", pages, index=current_index)

# Po:
page = st.selectbox("Select Page:", pages, index=current_index)
if page != st.session_state.current_page:
    st.session_state.current_page = page
    save_session()
    st.rerun()  # Okamžitý refresh
```

### 2. ✅ Oprava zobrazení reálných mockupů

**Problém:** Produkty zobrazovaly jen SVG placeholder ikony místo reálných mockup obrázků z Printify.

**Příčina:** Podmínka `if img_src:` způsobila, že když nebyl design nahrán, zobrazil se SVG fallback místo prázdného mockupu.

**Řešení:**
- Mockupy se nyní VŽDY zobrazují, pokud soubor existuje
- Design se aplikuje přes mockup, pokud je nahrán
- SVG fallback se používá pouze když mockup soubor neexistuje
- Lepší error handling s logováním

```python
# Klíčová změna:
else:
    # No design provided, show plain mockup (this is the key fix!)
    with open(mockup_path, "rb") as img_file:
        img_base64 = base64.b64encode(img_file.read()).decode('utf-8')
        img_src = f"data:image/png;base64,{img_base64}"
```
